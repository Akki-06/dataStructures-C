# Data Structures in C – Semester II (BCA)

This repository contains **concept-wise implementations of Data Structures using C**, developed as part of **BCA Semester II coursework**.  
The objective of this project is to build a strong foundation in data structures through clean, modular, and well-organized C programs following standard coding and version-control practices.

---

## 📚 Topics Covered

### 🔹 Trees
- Binary Search Tree (BST)
  - Insertion
  - Traversal
  - Deletion

### 🔹 Linked Lists
- Singly Linked List (SLL)
- Doubly Linked List (DLL)
- Circular Linked List (CLL)

### 🔹 Stack
- Stack using arrays
- Stack operations (push, pop, peek)

### 🔹 Queue
- Linear Queue
- Circular Queue
- Basic queue operations

### 🔹 Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort  
(Implemented for conceptual clarity and algorithmic understanding)

### 🔹 Searching Algorithms
- Linear Search
- Binary Search

### 🔹 Matrices
- Matrix operations
- Matrix representation using arrays

### 🔹 Polynomial
- Polynomial representation
- Polynomial addition using linked lists

### 🔹 String Operations
- Basic string manipulation programs
- Logical implementation without relying heavily on built-in functions
